# 当前 SARSA 的收益与惩罚因子

核对版本：reward-v1，2026-10-04。以 reward/engine.py、data/processing.py、environments/marketing.py 和 backend/service.py 为准。

“破坏因子”如果指影响回报的不利因素，准确名称是惩罚因子；如果指市场扰动，则属于状态输入，两者作用不同。

| 因子 | 回报方向 | 默认库存消化目标的权重 |
| --- | --- | --- |
| 营销贡献利润率 | 收益 + | 8% |
| 营销 ROI | 收益 + | 4% |
| 转化率 | 收益 + | 8% |
| 回流客户占比 | 收益 + | 4% |
| 库存周转 | 收益 + | 24% |
| 收入增长 | 收益 + | 12% |
| 新客占比 | 收益 + | 4% |
| 广告获客成本 | 惩罚 − | 4% |
| 退货率 | 惩罚 − | 4% |
| 额外促销成本率 | 惩罚 − | 4% |
| 库存压力 | 惩罚 − | 20% |
| 收入波动 | 惩罚 − | 4% |

每个原始指标先按固定范围进行 min-max 标准化，再截断到 [0,1]。12 项非负权重统一归一化，R 等于收益项加权和减去惩罚项加权和。网页“模型与因子 → 收益与惩罚”实时从后端读取实际范围、公式和七种目标的权重。它没有修改已训练模型或奖励函数。

例如库存消化目标中，库存压力从 0.8 降为 0.5，其他指标相同，扣分从 0.16 减为 0.10，综合回报增加 0.06。这个分数没有人民币单位，不能读成利润增加 0.06 元，也不能据此证明企业实际改善。

缺失项贡献为 0，不重新分配其权重；覆盖率用于标记缺失。缺失惩罚项可能使回报看起来较高，因此不得把缺失理解为风险低。

利润是扣除商品成本、广告、额外促销和退货损失后的营销贡献利润，不是完整会计净利润。回流客户占比是复购代理，库存周转是观察期销量 /（剩余库存 + 销量），并非年度财务周转次数。CSV 没有 cogs / unit_cost 时，商品成本按收入的 58% 估算；没有 return_loss 时，退货损失按退货件数 × 成交价 × 70% 估算，数据质量区会提示。

收入波动存在口径差异：CSV 使用最近至多七天收入的变异系数；仿真和单轮实际反馈使用绝对收入环比变化的代理。现阶段不同来源的 Reward 不直接比较。权重、标准化范围及库存覆盖阈值均为原型设定，未以三只松鼠内部数据校准；收益与成本指标也存在重叠，尚不能作为独立因果解释。

季节性、节日强度、竞品压力、平台流量变化和市场需求进入状态，帮助选动作，不直接扣分。预算、停用渠道、价格和毛利底线通过动作屏蔽限制执行。实际下一动作确认后，Deep SARSA 的训练目标才使用 R + γ Q(S′,A′)；终止周期只使用 R。LLM 负责语义理解和解释，不覆盖 SARSA 选定的动作。
