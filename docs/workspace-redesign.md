# 工作台改版依据（2026-10-04）

用户希望围绕三只松鼠，在一个界面完成数据查看与营销决策，并采用接近 Codex 的中性色工作区。保留可运行的 Deep SARSA 后端和实际反馈更新，改变操作入口和企业证据来源。

## 本轮实施

1. 首页收拢为单个工作台：场景和历史侧栏、营销决策主区、按需打开的数据与模型抽屉。数据库、模型运行与对照结果不再占据七个导航页面。
2. 三只松鼠公开资料写入 SQLite 的企业证据表；记录日期、报告期、指标、数值、来源与页码。日运营示例仍明确标注合成数据，不能把年报总额拆成日订单或客户数据。
3. 根据问题检索企业证据，把结果留在决策记录，并传给解释层。企业资料用于业务背景，实测指标仍决定 State，公开财务数据不覆盖日指标。无密钥时也能查看检索结果。
4. 页面采用灰白背景、炭黑操作按钮、明确的文字层级。Q 值、因子、训练与更新凭证保留在展开项和抽屉中。
5. 手机共享增加局域网启动入口、实际网络地址和二维码。局域网与公网分别标注；Render 公网发布仍取决于可用托管账号。禁止给手机生成指向 127.0.0.1 的共享二维码。

## 已有技术与研究定位

[HOBA](https://arxiv.org/abs/2607.24779) 采用 LLM 处理上层策略配置、SARSA 选择中层执行专家、底层模型执行广告竞价。本项目的 SARSA 直接选择渠道预算、促销等经营动作，执行频率和数据粒度不同。因此不能宣称首次融合 LLM 与 SARSA，也不能把论文的实验提升当作本系统的效果。

[Towards A Unified Agent with Foundation Models](https://arxiv.org/abs/2307.09668) 已探索用语言模型支持强化学习中的经验利用、技能调度与观察学习。上述论文提供算法思路，没有规定企业产品必须有哪些网页。本轮的一主区与抽屉设计，是根据用户的实际操作流程做出的产品判断。

| 比较项 | 本系统的具体研究方向 | 本轮状态 |
|---|---|---|
| 企业上下文 | 来源、日期和报告期可追踪的三只松鼠证据检索 | 实施 |
| 营销动作 | 跨渠道投入、促销、库存与毛利约束共同作用 | 保留现有实现 |
| 实际学习 | 使用人工确认的 A′；区分仿真与实际反馈 | 保留并回归验证 |
| 经营目标 | 多目标权重与缺失覆盖可查 | 保留现有实现 |
| 因果评估 | 小预算随机对照、倾向概率与增量利润评估 | 研究计划，未实施 |
| 稳定性 | 多训练种子、奖励设计与真实环境参数校准 | 待进一步实验 |

本轮增加证据检索和交互收拢，并不构成新的 SARSA 数学算法。比赛中适合表述为“面向三只松鼠营销业务的应用与系统改进”；是否形成算法创新，需要新的方法及充分对照实验。检索不到某种组合，也不能直接证明原创。
