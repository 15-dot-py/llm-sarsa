# 比赛现场操作（3–5 分钟）

1. 打开工作台，先说明“三只松鼠营销场景，日运营使用合成示例”。右侧企业资料展示真实的公开来源，说明其与日级数据分别保存。
2. 左侧选择“渠道投入与获客”或“坚果大促与库存”，检查经营目标、预算与毛利底线，输入需要决策的问题。
3. 生成建议，展示检索的企业证据和来源。需要解释模型时打开“查看模型依据”，查 Q 值、屏蔽原因与输入因子。明确动作来自 Deep SARSA，解释为实际 LLM 或模板，不掩饰未配置 API。
4. 点击确认执行，在反馈里选合成环境演示。说明这个按钮真实运行随机转移，但并非企业业绩。
5. 结果会生成下一建议；确认下一实际动作后展示更新凭证：S、A、R、S′、A′、TD Target、Loss、模型更新次数。
6. 下一轮反馈勾选结束周期，避免无限停留在下一动作。也可在下一建议尚未执行时结束周期，系统按终止状态更新。
7. 打开“模型”侧栏，在训练记录与对照结果之间切换，展示相同测试种子和实际结果。指出“当前没有证明语义辅助必然更优”，说明后续要在真实数据与小预算对照中检验。
8. 历史导出 JSON，展示建议与实际动作分别保存，Reward 每一项都能解释。

需要重新演示时，到“数据”侧栏创建新会话；不会覆盖其他会话的数据与模型。同一 Wi-Fi 演示使用“手机共享启动.cmd”和网页中的局域网二维码；任意网络访问需要实际 Render 公网发布。不要把 127.0.0.1 印在评委二维码上。

展示表述建议：系统把问题转成有来源的因子，用序贯模型选择约束内动作，再以经营结果更新。已有原型证明流程可以运行，营销收益提升仍需业务验证。
