# 执行记录、浏览器恢复与负数指标

## 已确认的问题

旧前端在工作区返回 401 时会删除会话标识并创建空工作区。Render 免费实例使用临时文件系统，部署或实例替换后 SQLite 文件可能消失。这两个行为组合，会让成功保存的执行记录在更新后看起来不存在。

执行确认与人工改选动作也使用了不同口径：采纳模型建议会保存 execution、时间戳和实际动作，但 override 为 false；只有选择其他合法动作才计入人工调整。风险分析需要预测、执行依据及经营反馈，不能用“暂不评分”推断用户没有操作。

## 当前处理

- 每次决策、执行确认、经营反馈、数据导入后，取得服务端签名的完整工作区备份并保存到本浏览器 IndexedDB。读取工作台时也保存最新备份。
- 备份包含经营数据、全部决策、SARSA checkpoint、转移和训练记录；模型旧版本归档一并保存。恢复保留同一工作区和待确认的实际下一动作。
- 仅在 `workspace_expired` 时恢复；登录失效不会新建工作区或自动重发到其他工作区。并行请求共用一次恢复。
- 验证服务端 HMAC 签名后才解析 checkpoint，恢复上限为解压后 16 MB。备份不能覆盖服务端已有的较新记录，已登录账号备份只能恢复给原账号。
- 备份失败会显示警告，但不会把已经成功的执行确认改为失败。每次确认与反馈保持原有幂等和 on-policy SARSA 更新规则。
- 决策记录中可以导出完整恢复备份、导入备份或切换本浏览器保存的工作区。JSON 历史导出包含全部记录，页面显示最近 200 条。

`AUTH_SECRET` 至少 32 字符并在部署间保持不变；`WORKSPACE_BACKUP_ENABLED=true` 启用备份。不要把签名密钥提交 GitHub。更换签名密钥后，旧签名备份无法恢复。

这是免费演示环境的设备恢复机制，不能代替服务端持久数据库。清除浏览器数据、使用无痕模式或换设备，不会自动获得原设备备份；换设备可以手动导入导出的完整备份。更新前已经丢失且没有备份的记录无法凭访问日志重建。手机号账号与短信账本仍需服务端可靠存储，`AUTH_STORAGE_CONFIRMED` 保持 false。

## 负数指标的解释

顶部贡献利润与 ROI 来自当前数据库或已提交的经营反馈。输入问题只影响目标、语义信号和约束；点击确认只记录执行，不会伪造后续营收。只有经营反馈或数据导入更新实际观察值。

营销贡献利润 = 收入 − 商品成本 − 广告费 − 促销成本 − 退货损失。

营销 ROI = 营销贡献利润 ÷（广告费 + 促销成本）。广告费与促销成本合计为零时，ROI 缺失。

Q 是折扣累计综合回报，Reward 是收益与惩罚的加权分数，均不以元计价。Reward、Q、当期利润可能符号不同。页面保留负数，展示成本口径和反馈前后差值；不会承诺模型能保证盈利。

回归测试覆盖正负反馈、确认与改选计数、空实例恢复、实际 A′ 单次更新、旧备份防回滚、篡改签名拒绝及超过页面上限的完整记录留存。

## 演示波动与建议切换

原演示反馈使用决策 UUID 派生随机种子，同样的数据、同样动作在新建决策后也会抽到另一种市场环境。现在以观察日与主要经营指标的稳定序列化内容派生种子，换决策编号不会改变环境结果。不同动作在同一观察状态下使用相同外部扰动；新观察日及经营指标变化仍可能产生不同结果。

同一反馈周期沿用首轮问题的已审计语义信号，避免每期重新调用 LLM 解释相同原文而引入额外变化。展示决策使用 explore=false；当前 epsilon 只用于训练探索，不能解释展示动作随机切换。

状态、目标、约束、模型版本都会影响合法动作排名。新记录保留最高与次高合法 Q 值差距及候选动作；差距不是统计置信度。SARSA 仍按实际确认的 A′ 更新，不做平滑假学习或伪造收益。连续三次增加预算 10% 会将该渠道预算提高到起始值的 1.331 倍，不能按每轮独立的 10% 理解。

合成环境仍使用假设的渠道响应和随机扰动；用观察数据初始化预算、价格、库存等控制变量，不等于估计企业的完整因果响应。预测区间和反馈结果继续标注仿真，不能用于证明三只松鼠实际营销效果。
