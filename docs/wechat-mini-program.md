# 微信小程序接入与发布

## 当前实施方案

使用微信原生 WXML、WXSS、JavaScript 客户端；登录和工作台是两个主要页面，隐私说明另设阅读入口。客户端复用 FastAPI、运营数据库、LLM、Deep SARSA、执行确认与奖励反馈，不另建聊天机器人，也不在手机运行模型。

手机号经腾讯云验证码校验后创建账号。后端用不可猜测令牌认证，登录默认7天过期，网站使用 HttpOnly Cookie，小程序使用 Bearer 令牌。账号可以创建多个工作区，各账号只访问自己的工作区。验证码不发回页面、不写日志，数据库不保存明文手机号或明文验证码。

## 免费短信的真实边界

截至2026年10月6日，腾讯云价格说明规定首次开通个人认证主体赠送100条、企业认证主体赠送200条，有效期3个月，需0元领取。使用须知中的企业500条说明与价格页不一致，本项目按较新价格页记录，不承诺500条或永久免费。首次赠送与实名主体绑定，不能依靠重复注册无限领取。

短信仍须审核通过的资质、签名和验证码模板。2025年9月18日起个人自用短信签名不再支持创建；个人账号需使用企事业单位的授权他用签名。学校主体可评估事业单位资质，不能替三只松鼠冒用企业资质。

系统只接入正式 SendSms 接口。默认 SMS_SEND_ENABLED=false、SMS_SEND_LIMIT=0，不发真实短信、不购买套餐。启用前必须核实账号的免费包余额和到期日，设置额度标识、发送次数上限与到期时间。次数上限不是上游余额查询，若账号还用于其他短信业务，应进一步缩小上限，供应商控制台也应关闭超额付费通道。网络超时不自动重试，可能已被受理的请求仍计入上限。

## 现有网站与小程序分别发布

GitHub 保存客户端与后端源码；Render 继续运行 Python 后端。正式微信小程序需要独立的小程序账号 AppID、开发者权限、合法服务器域名配置、必要的备案、隐私声明、代码上传与微信审核。网址二维码只能打开网页，不能充当正式微信小程序码。

客户端 config.js 的 Render 地址用于后端集成，尚未通过微信域名配置检查。project.config.json 的 touristappid 仅用于打开代码，不能上传发布。不会通过关闭 urlCheck 伪装正式验收。若微信后台无法接受当前 onrender.com 域名，应使用已具备条件的自有域名或经授权的微信云托管方案，再更新客户端域名。

## 后端配置

详细字段见 .env.example，真实凭证只放本机私有 .env 和服务环境变量。AUTH_SECRET 至少32字符。AUTH_REQUIRE_LOGIN=true 保护工作台 API；未配置真实短信前保留原网站演示方式，小程序始终先要求登录。

AUTH_STORAGE_CONFIRMED 只有在账号、验证码计数和模型数据库具备可靠持久存储后才可设为true。当前 Render 免费服务没有持久磁盘，不能直接开启真实账号短信登录，否则重新部署会丢账号、重置发送计数；此开关默认false。不能为了完成界面演示假定已拥有持久化存储。

SMS_TEMPLATE_ID 对应一个变量的已审核验证码模板，例如“您的登录验证码为{1}，5分钟内有效。非本人操作请忽略”。签名应为实际授权主体，而不是随意填写项目名。

## 发布顺序

1. 核实微信账号、主体、开发者权限及短信实名、签名、模板、免费包。
2. 解决后端持久存储、合法域名与隐私声明；对服务主体和实际处理地点作真实披露。
3. 在微信开发者工具导入 miniprogram，将 touristappid 换为已验证的 AppID；保留域名校验。
4. 真机验证：发到测试者本人手机号，错误、过期、重复验证码被拒绝；跨账号访问被拒绝；实际决策与反馈闭环可用。
5. 上传开发版，设置体验版及体验成员，取得真实体验码；体验版并不对任意微信用户开放。
6. 提交微信审核，审核通过后发布正式版。配置 WECHAT_APP_ID、WECHAT_APP_SECRET 并确认 WECHAT_RELEASE_CONFIRMED=true，后端 /api/wechat/code 才调用微信官方接口生成正式码。公网调用该接口需要管理员令牌。

## 验收范围

pytest 验证登录、验证码限频与额度、失败保守计数、账号隔离、撤销凭证、注销与跨站请求。miniprogram/check.cjs 仅做本地清单、JavaScript、事件与操作契约检查，不等于微信编译、真机或审核通过。真实短信和小程序正式码都须实际外部服务验证。
